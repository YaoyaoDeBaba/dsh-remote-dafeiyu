# 序列帧精灵图：方法论

> 工具能替你做"算"，替不了你做"判断"。这篇写的是**判断**：量什么、在哪个坐标空间量、量错了怎么自证。
> 工具清单与参数表在 `references/tools.md`，症状速查在 `references/symptoms.md`。

## 1. 三个概念必须先分清

| 概念 | 定义 | 谁定 |
|---|---|---|
| **语义点** | "身高上端/下端"、"锚点横轴"这类**与素材无关的角色概念** | 需求方定，**不能替换**（换成腰线就不是身高了） |
| **路标** | 用哪个像素/颜色/形状去定位那个语义点 | 执行者自由选（选"易分辨、可重复、不被遮挡误伤"的） |
| **坐标空间** | 源帧 / 裁剪框 / 输出格子 | 工具链决定，**每次报数必须声明** |

最大的坑是把**自己的路标当成语义点**（用"身体中轴"近似"锚点横轴"，系统性偏 5~11px）。

## 2. 坐标空间与换算（混层 = 必错）

```
源帧 px ──(−trim.x, −trim.y)──> 裁剪框 px ──(×scale)──> 格子 px ──(/cellW,cellH)──> 归一化 0~1
```

1. **一切测量在源分辨率做**。缩放通常 0.35~0.5，格子上 1px 误差 ≈ 源帧 2~3px；
2. 归一化锚点是**相对输出格子**的（运行时按格子画），而测量值与 `span` 是**相对源帧**的；
3. 每个中间量都要带空间标签（`space:"frame"|"crop"|"cell"`），没有标签就当作可疑。

## 3. 身高与锚点必须分开处理

| 项 | 改它等于改什么 | 改错怎么修 |
|---|---|---|
| 身高（`charHeightPx` / `span`） | **像素**（缩放比例） | 必须重新导出 |
| 锚点（`anchorX/anchorY`） | **元数据** | 改 JSON 即可，零成本 |

→ **先把尺寸一次做到位，再慢慢调锚点**。反过来会白白重导很多次。

## 4. 语义点的通用测法（与素材无关）

1. **多截面对照**：同一点采样多列/多行，取统计量（min/median）。单点必被局部干扰骗（呆毛/手/特效）；
2. **连续长度阈值**：用"连续 ≥N 像素"筛掉细长附属物，N 用**相对尺度**（主体高度的 15%~25%），不要写死像素；
3. **颜色语义要写对**：找"白"用 `channel:"whiteness"`（低饱和 + 高亮度），**不要用 `r,g,b>200`**——肤色 `(240,220,207)` 会全通过，线就穿到额头；
4. **边界别靠 alpha**：alpha 阈值会把阴影/抗锯齿算进来，优先用"颜色 + 连续性"的行/列判据。

## 5. 特征匹配优先于启发式

小尺寸、稳定的特征（纽扣、徽章、接缝、眼睛）比任何规则都准：

1. 在参考帧上截一块（20~40px 见方，含该特征及邻域）；
2. 对其它帧/素材做 NCC，取峰值；
3. **score 阈值**：>0.90 可信（误差 <1px）；0.85~0.90 谨慎；<0.85 视为失败，降级到规则法。

## 6. 自校准：新公式必须先复现"已知正确"的样本

任何新推导的公式/参数，先在**已人工确认的那一条**上复现：代入 → 与已知值比对 → 误差 ≤1px 才允许推广。
复现失败先查公式（单位/坐标空间），**不要**急着套到其它素材上。跳过这一步就是 5~11px 的系统性偏移。

## 7. 剪影拟合（同角色批量对齐的主力）

前提：同角色的动画里通常存在"姿势接近"的帧。

1. 取参考素材某帧当尺子；对目标动画**全序列**做剪影匹配，掩膜用 `body-core`（最大连通域/轻度腐蚀）去掉特效与道具；
2. 得到 `IoU / scale / (dx,dy)`，按三档处理：

| IoU | 含义 | 处理 |
|---|---|---|
| ≥0.90 | 有同姿势帧 | 缩放与平移都可信 → **拓印锚点** |
| 0.75~0.90 | 姿势接近 | 剪影**只定缩放**；锚点走语义点 |
| <0.75 | 无同姿势帧 | 剪影仅作参考 → **全程语义点**，标 `confidence:low` |

3. 提精度：全分辨率精搜（±4px/1px、scale ±0.02/0.005）、IoU 曲面亚像素插值、只比躯干+头、top-N 帧投票取中位数。

## 8. 特征反推（姿势差异大时的首选）

人的**不变特征**（眼睛、头饰、纽扣）不随肢体移动。把目标动画的特征与 idle 的特征对齐（缩放+平移），就得到同一坐标系下的对应关系——身高自然对齐，锚点也能反推。

- **特征优先级**：头部特征（双眼一起、发带装饰）> 躯干特征（纽扣列、徽章）>> 手脚/尾巴/披风下摆（不要用）；
- **双特征**用两点间距比值定 `scale`，单特征只能定平移；
- 反推公式（**方向别搞反**）：`p_target = (p_idle − origin) × scale + (x, y)`；
- `score ≥0.90` 且双特征残差 <2px → 可信；0.80~0.90 → 与语义点交叉验证，差 >3px 以语义点为准；<0.80 → 放弃。

## 9. 验证闭环（**导出成功 ≠ 结果正确**）

1. **成品复量**：在导出后的图上用同一套判据再量一次身高/锚点——`achievedPx` 只是参数回显；
2. **组内一致性**：同一批身高方差 ≤1%、锚点 X 偏差 ≤2px（源）；
3. **大图准绳**：全部动画按锚点对齐到同一地平线 + 画头顶线，目视一遍；
4. **误差预算**：边缘 ±1、语义点 ±2、模板 ±1、缩放 ±0.5% → 累计 ≤0.5% 身高 / ≤2px 锚点。超了就查是哪一步，别继续微调。

## 10. 交付前自检清单（只靠数值就能判断这批准不准）

- [ ] 公式在参考素材上复现 ≤1px；
- [ ] 组内身高方差 ≤1%（**成品实测**，不是参数回显）；
- [ ] 锚点与"独立测得的语义值"偏差 ≤2px（源）；
- [ ] 剪影 IoU 全部回报，<0.75 的条目点名并标低置信；
- [ ] 每条 meta 字段齐全：`name / cols / rows / cellWidth / cellHeight / charHeightPx / scale / anchorX / anchorY / anchorYTopDown / anchorConvention / fps`；
- [ ] 任一条超预算 → **不交付**，并列明超的是哪一步。

## 11. 参考案例（只是例子，不是规则）

> 下面是「Q 版鲸鱼娘 8×6 序列帧」的具体实现，换素材要重新选路标。

| 语义点 | 案例路标 | 参数 |
|---|---|---|
| 身高上端 | 蓝发与白发带交界（发带下沿） | `whiteness`；多列投票取 min；`minRun≈0.25×帧高` |
| 身高下端 | 鞋底最低边界 | 深色 `luma<110` 在中央 40% 连续 ≥12px 的最低行 |
| 锚点横轴 | 胸襟门襟纽扣列 | 源帧模板匹配，score 0.91~1.00 |

实测基线：同角色 6 条（头宽 474±5）；剪影 IoU 站立类 0.92~0.95、动作类 0.55~0.72；门襟模板 score 0.91~1.00，idle 复现 0.4164。
